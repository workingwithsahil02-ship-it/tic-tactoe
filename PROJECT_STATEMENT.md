# Project Statement

## Problem Statement

Tic-tac-toe is a game almost everyone knows, but sometimes you don't have a pen and paper or a friend sitting next to you to play. I wanted to make a version that runs on the computer so you can play anytime, either with another person or alone against the computer. It was also a good way for me to practice the basics of Python like loops, functions, lists and input handling.

## Target User

- Anyone who wants a quick game to pass time
- Two people sharing one computer who want to play against each other
- Beginners or students learning Python who want a simple example of a small game project
- Younger kids or casual players, since the game is easy to understand and only needs numbers 1-9

## Features

- **Two game modes:** play against a friend or against the computer
- **Custom player names:** each player can enter a name, or leave it blank for a default one
- **Simple number-based controls:** pick a spot on the board by typing 1-9
- **Input validation:** the game handles letters, out-of-range numbers and already-taken spots without crashing
- **Win and tie detection:** it checks all 8 possible winning lines after every move and announces the result
- **Computer opponent:** the computer picks a random open spot each turn (not very smart yet)
- **Clear board display:** the board is printed after every turn so it's easy to follow

## Limitations

- The computer opponent is random, so it isn't a challenge for experienced players
- No play-again option or score tracking
- Terminal only, no graphical interface
